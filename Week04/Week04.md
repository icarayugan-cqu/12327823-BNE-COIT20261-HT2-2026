## Reflection
This week's tutorial provided practical experience with configuring and testing a network in GNS3. I learned how important it is to correctly configure IP addresses and verify connectivity between different hosts before performing further network activities. Using commands such as ping helped me confirm whether devices could communicate successfully, while the ip addr command allowed me to check the network interfaces and assigned IP addresses.
